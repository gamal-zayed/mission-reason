# Figures

This directory contains figures used in the MissionReason documentation and publications.
 
MissionReason Dataset v0.2 is added, comprising 4,000 scenario-decision pairs. Dataset balance is validated after filtering and applying more distributions. The first two figures show some insights on the generated dataset first, then the train evaluation.

In the Self-analysis figure, we regenerated 11 faults adopted by (Anderson et al.) while seeking dataset imbalance analysis. we could see that the Skip action is the least occurring as this makes sense in Satellite Missions.
